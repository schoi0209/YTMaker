# 🎬 YTMaker — 유튜브 영상 제작기

AI 기반 유튜브 영상 제작 올인원 도구

## 기능
- 🔍 주제 입력 → AI 리서치 & 콘텐츠 설계
- 🎣 어그로 훅 5개 자동 생성
- 📋 타임라인 & 스크립트 구조 설계
- 🍌 나노바나나2 (Gemini 3.1 Flash Image) 썸네일 자동 생성
- 🎬 캡컷 씬별 편집 지시서 출력
- 📊 유튜브 메타데이터 (제목/설명/태그) SEO 최적화

## 사용법
`index.html` 파일을 브라우저에서 열거나 GitHub Pages로 배포하세요.

## 기술 스택
- Claude Sonnet API (콘텐츠 설계 / 메타데이터)
- Google Gemini 3.1 Flash Image API (나노바나나2 썸네일)
- Vanilla HTML/CSS/JS
